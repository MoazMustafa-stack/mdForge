# Basic Markdown Syntax

This file tests the basic building blocks of Markdown.

## Headings

# H1 Heading
## H2 Heading
### H3 Heading
#### H4 Heading
##### H5 Heading
###### H6 Heading

## Emphasis

- *Italic text* with asterisks
- _Italic text_ with underscores
- **Bold text** with double asterisks
- __Bold text__ with double underscores
- ***Bold and italic*** with triple asterisks
- ~~Strikethrough text~~

## Lists

### Unordered List
- Item 1
- Item 2
    - Sub-item 2.1
    - Sub-item 2.2
- Item 3

### Ordered List
1. First item
2. Second item
    1. Sub-item A
    2. Sub-item B
3. Third item
